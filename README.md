# RGB 去噪练习项目

这是一个**练习性质的计算机视觉上手项目**。它不追求工业级效果，也不追求复杂的数据集和最强模型，而是尽量用一套容易读懂、容易修改、容易复现实验的代码，帮助刚入门 CV 的同学快速走完一次完整流程：

- 自己生成数据
- 自己定义退化过程
- 自己搭建网络
- 自己训练、验证、测试
- 自己把结果可视化

项目当前任务是：**RGB 图像去噪与缺失恢复**。

更具体地说，我们先合成一张干净的 RGB 图，再人为加入：

- 高斯噪声
- 少量随机掩码缺失

然后让网络学习从退化图恢复出干净图像。

## 1. 项目定位

这个项目适合下面这几类同学：

- 刚接触 PyTorch，想找一个比 MNIST 稍微更像“图像恢复任务”的练手项目
- 想理解数据生成、模型、训练、验证、可视化是怎么串起来的
- 想在一个小项目里练习改数据、改网络、改损失函数
- 想把“看论文里的图像恢复流程”变成自己能跑通的代码

这个项目**不太适合**下面这种目标：

- 直接追求 SOTA 效果
- 直接在真实工业数据上部署
- 直接和成熟图像恢复 benchmark 做严格对比

因为这里的数据是**合成数据**，场景和退化方式都是人为控制的，主要目标是教学和练习。

## 2. 当前任务是什么

当前版本不是超分辨率，而是**RGB 图像恢复**任务。

每个样本都包含三部分核心内容：

- `clean.npy`：干净的 RGB 图像
- `degraded.npy`：加入噪声并挖掉部分像素后的退化图像
- `mask.npy`：记录哪些像素是有效的、哪些像素被掩掉

也就是说，网络学习的是：

`退化 RGB 图 -> 干净 RGB 图`

当前代码里，掩膜也会一起送进模型，作为额外输入通道参与恢复。这个设计是为了让网络显式知道哪里是缺失区域。

## 3. 数据是怎么生成的

数据由 [generatedata.py](./generatedata.py) 自动生成。

### 3.1 干净图像

每张干净图像大小是 `128 x 128`，是一个 RGB 三通道图像。

图像不是从真实数据集裁出来的，而是程序合成的，内容主要由这些元素组成：

- 圆形
- 方形
- 三角形
- 数字字符

这些元素会有随机的：

- 颜色
- 位置
- 大小
- 旋转角度
- 清晰/模糊状态

这让数据足够简单，便于理解，同时又比纯黑白玩具数据更接近真实的图像恢复场景。

### 3.2 背景

背景不再固定为纯黑色，而是带有一定随机性的彩色背景：

- 随机基础底色
- 轻微颜色渐变
- 轻微纹理噪声

这样做的好处是：

- 避免模型只在“黑底彩图形”这种过于单一的分布上训练
- 让恢复任务更接近真实图像，而不是只学习几何图形边缘

### 3.3 噪声

当前版本使用的是**高斯噪声**，噪声标准差随机采样。

代码中的当前配置是：

- `GAUSSIAN_NOISE_STD_RANGE = (0.12, 0.15)`

这代表每张图的噪声强度会在一个范围里变化，而不是所有样本都一样。

### 3.4 缺失掩码

除了高斯噪声之外，图像还会加入少量随机缺失。

当前配置特点：

- 缺失比例较小，范围是 `1% ~ 6%`
- 缺失块尺寸较小，范围是 `2 ~ 6` 像素
- 缺失位置不是完全无规则乱撒，而是借助网格策略做得更均匀

这样设计的目的，是让缺失更细颗粒、更分散，而不是出现大块黑洞。

### 3.5 数据目录结构

生成后，`data/` 目录下每个样本会是一个单独文件夹，例如：

```text
data/
  000/
    clean.npy
    degraded.npy
    mask.npy
    comparison.png
    meta.txt
```

其中：

- `comparison.png` 用来快速查看这个样本的干净图、退化图和掩膜
- `meta.txt` 记录该样本的噪声强度和实际掩膜比例

## 4. 模型结构

模型定义在 [model.py](./model.py)。

当前主模型名是 `RGBDenoiseNet`。

从结构上看，它更像一个适合练手的小型编码器-解码器网络，带有并联卷积特征提取和跳跃连接。它不是为了炫复杂结构，而是为了让初学者能看清楚“编码、下采样、上采样、特征融合”这些基本概念。

### 4.1 模块组成

主要模块包括：

- `Conv2d`
- `ConvBlock`
- `MultiConvLayer`
- `UpBlock`
- `Encoder`
- `Decoder`
- `RGBDenoiseNet`

### 4.2 MultiConvLayer

`MultiConvLayer` 是这个项目里比较值得学习的部分。

它会并行做三种卷积：

- `3x3`
- `1x7`
- `7x1`

然后把三路特征 `concat` 到一起，再用 `1x1 conv` 融合。

你可以把它理解成一种非常轻量的“局部纹理 + 方向边缘特征提取”：

- `3x3` 分支主要负责局部纹理和常规细节
- `1x7` 分支更容易感受到水平方向的拉伸结构和边缘
- `7x1` 分支更容易感受到垂直方向的拉伸结构和边缘

对去噪和恢复任务来说，这种把普通局部卷积和方向性卷积并联起来的做法，能帮助网络同时关注细节和平滑区域中的方向变化。

### 4.3 编码器和解码器

编码器负责逐步下采样、提取更高层语义特征。

解码器负责逐步上采样，把低分辨率特征恢复回原始图像大小。

### 4.4 跳跃连接

当前网络使用的是 **concat 跳跃连接**。

也就是在解码阶段，把上采样后的特征和编码阶段对应层的特征拼接起来，再继续卷积融合。这种做法对图像恢复任务很常见，因为它可以帮助网络保留浅层细节。

### 4.5 输出

模型最后输出一个 `3` 通道 RGB 图，并通过 `torch.clamp(output, 0.0, 1.0)` 限制到合法图像范围。

## 5. 数据如何喂给模型

数据集定义在 [utils.py](./utils.py) 的 `DenoisingDataset` 中。

读取一个样本时，会返回：

- 退化图 `degraded_tensor`
- 干净图 `clean_tensor`
- 掩膜 `mask_tensor`

其中：

- 图像张量格式是 `C x H x W`
- 掩膜张量格式是 `1 x H x W`

当前训练代码会把：

- `RGB 退化图`
- `mask`

沿通道维拼接，组成 `4` 通道输入送进模型。

也就是说，当前模型输入维度是：

- `3` 个 RGB 通道
- `1` 个 mask 通道

总共 `4` 通道。

## 6. 训练流程

训练入口在 [run.py](./run.py)。

整体流程如下：

1. 读取 `data/` 数据集
2. 按 `7:1:2` 划分训练集、验证集、测试集
3. 创建 `DataLoader`
4. 初始化模型、损失函数、优化器、学习率调度器
5. 进行多轮训练
6. 每轮结束后在验证集上评估
7. 最终在测试集上评估并保存可视化结果

### 6.1 当前默认超参数

当前代码里的主要超参数如下：

- `BATCH_SIZE = 25`
- `LEARNING_RATE = 0.0006`
- `EPOCHS = 300`
- `SCHEDULER_STEP_SIZE = 30`
- `SCHEDULER_GAMMA = 0.5`

这些参数不是“标准答案”，只是一个适合练手和观察曲线的起点。

### 6.2 损失函数

当前训练使用：

- `nn.MSELoss()`

也就是均方误差损失。

对入门项目来说，它足够简单，便于理解。

如果后面你想继续做实验，可以自己尝试：

- `L1Loss`
- 掩膜加权损失
- 感知损失
- SSIM 类损失

## 7. 验证与可视化

验证逻辑在 [validation.py](./validation.py)，可视化逻辑在 [visualize.py](./visualize.py)。

### 7.1 验证

验证阶段会：

- 切到 `eval()` 模式
- 关闭梯度
- 遍历验证集
- 统计平均损失

### 7.2 可视化结果

测试完成后，会输出一些示例图，通常包括：

- 退化输入
- 模型输出
- 干净真值
- 误差图

同时还会画出训练集和验证集的 loss 曲线。

这对初学者非常重要，因为：

- 看数字只能知道“损失变小了没有”
- 看图才能知道“模型到底学到了什么”

## 8. 如何运行

建议在 Python 3 环境下运行。

### 8.1 安装依赖

项目根目录下有一个 [requirements.txt](./requirements.txt)，但当前文件里只列出了一部分依赖。

这个项目实际还需要：

- `torch`
- `tqdm`

因此建议你手动安装完整依赖，例如：

```bash
pip install -r requirements.txt
pip install tqdm
```

PyTorch 建议按官方方式安装，因为不同电脑的 CUDA / CPU 版本可能不同。

例如 CPU 版本可以参考官方命令自行安装：

```bash
pip install torch
```

如果你有 NVIDIA GPU，建议去 PyTorch 官网选择对应 CUDA 版本的安装命令。

### 8.2 先生成数据

```bash
python generatedata.py
```

运行后会在当前目录生成 `data/` 文件夹。

### 8.3 再启动训练

```bash
python run.py
```

训练结束后，模型权重会保存为：

```text
rgb_denoise_net.pth
```

同时测试可视化会输出到：

```text
test_visualizations/
```

## 9. 代码结构导读

项目结构很小，适合边跑边读：

```text
.
├─ generatedata.py
├─ model.py
├─ run.py
├─ utils.py
├─ validation.py
├─ visualize.py
├─ requirements.txt
└─ data/
```

各文件作用如下：

- `generatedata.py`：生成干净图、加噪声、加掩膜、保存样本
- `model.py`：定义网络结构
- `run.py`：训练主入口
- `utils.py`：定义数据集读取类
- `validation.py`：验证逻辑
- `visualize.py`：训练曲线和样本可视化

## 10. 这个项目适合怎么学

如果你是刚入门，建议不要一上来就疯狂改模型，而是按下面顺序练习。

### 第一阶段：先跑通

- 成功生成数据
- 成功启动训练
- 能看到 loss 曲线
- 能看到测试可视化

如果这一阶段没问题，说明你已经把一个最基本的 CV 训练闭环跑通了。

### 第二阶段：看懂数据

建议你重点观察：

- 干净图长什么样
- 噪声有多强
- 掩膜缺失有多严重
- 背景颜色和纹理如何变化

很多模型问题，本质上其实是数据问题。越早学会看数据，越能少走弯路。

### 第三阶段：看懂网络

建议你先弄清楚这些问题：

- 输入为什么是 4 通道
- 跳跃连接为什么要 `concat`
- 并联的局部卷积和方向卷积为什么可能有帮助
- 为什么最后输出是 3 通道

### 第四阶段：自己改实验

这是最推荐的部分。这个项目本来就是练手用的，所以非常适合自己改。

你可以尝试：

- 改噪声强度
- 改掩膜比例
- 改背景纹理强度
- 改 shape 数量
- 改 batch size
- 改学习率
- 改损失函数
- 改激活函数
- 改是否使用掩膜作为输入

## 11. 适合作为练习题的改动方向

如果你想把这个项目继续当作课程作业或自学练习，可以做下面这些扩展。

### 数据层面

- 把当前几何图形换成更复杂的程序纹理
- 引入运动模糊、椒盐噪声、条纹噪声
- 让掩膜从“小块缺失”变成“细线缺失”或“随机点缺失”
- 加入更丰富的背景分布

### 模型层面

- 把 `ReLU` 换成 `LeakyReLU` 或 `PReLU`
- 调整通道数
- 减少或增加网络深度
- 比较有无 BatchNorm 的差异
- 尝试更标准的 U-Net

### 训练层面

- 使用掩膜加权损失
- 只统计有效区域损失
- 只统计缺失区域损失
- 对不同噪声强度分开评估
- 记录 PSNR 或 SSIM

## 12. 当前实现的注意事项

这部分很重要，因为它能帮助初学者区分“我想做什么”和“代码现在实际做了什么”。

当前代码的几个关键事实如下：

- 当前模型输入是 `4` 通道，不是纯 `3` 通道
- 掩膜目前会进入模型
- 当前损失函数是普通 `MSELoss`，并没有对掩膜区域做特殊处理
- 当前数据是完全合成的，不是真实采样图像
- 当前 `requirements.txt` 没有完整列出所有依赖

如果你后续修改了这些设定，记得同步更新文档，否则很容易出现“代码和 README 对不上”的情况。

## 13. 为什么这个项目适合入门

因为它满足一个很重要的原则：

**小，但完整。**

它虽然小，但包含了一个 CV 项目里最关键的环节：

- 数据
- 模型
- 训练
- 验证
- 可视化

你在这里学到的很多习惯，都可以迁移到更大的项目中：

- 先看数据，再谈模型

- 先用可解释的小实验建立直觉

## 14. 一个实用建议

如果你是第一次做这种项目，不要把目标定成“把指标做到最好”，而要先定成：

- 我能不能把每个文件的作用讲清楚
- 我能不能解释每个张量的 shape
- 我能不能说清数据退化是怎么做的
- 我能不能看懂训练曲线为什么会变成这样

当你能把这些事情讲清楚的时候，这个练习项目就已经发挥它最大的价值了。
